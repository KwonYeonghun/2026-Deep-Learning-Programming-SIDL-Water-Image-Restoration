# SIDL Water Image Restoration

2026년 1학기 딥러닝 프로그래밍 수업에서 진행한 이미지 복원 프로젝트입니다.

## 프로젝트를 시작하며

SIDL 데이터셋의 여러 오염 유형 중에서 Water를 선택했습니다. 물방울이 맺힌 부분과 깨끗한 부분이 한 이미지 안에 같이 존재하는데, 복원 모델에 물방울의 위치를 미리 알려주면 성능이 좋아지지 않을까 생각했습니다.

기존 NAFNet에 U-Net 검출기를 추가하고, 검출기가 만든 마스크를 RGB 이미지와 함께 입력하는 방식으로 실험했습니다. 검출기는 별도로 학습한 뒤 고정했습니다.

## 실험 과정

처음에는 마스크 하나를 추가했지만, 검출기의 채널 수에 따라 마스크의 형태가 달라졌고 난이도별 복원 성능에도 차이가 있었습니다. 이후 NAFNet의 크기를 늘리거나 마스크의 최솟값을 제한하는 방법을 비교했고, 마지막에는 서로 다른 두 마스크를 동시에 입력했습니다.

| 모델 | 변경 내용 | Avg PSNR (dB) | SSIM |
| --- | --- | ---: | ---: |
| v0 | NAFNet baseline | 22.57 | 0.8263 |
| v1 | U-Net 검출기 추가 (c=16) | 22.60 | 0.8240 |
| v2 | 검출기 채널 수 증가 (c=32) | 22.43 | 0.8299 |
| v3 | v1 + NAFNet capacity 증가 | 23.12 | 0.8348 |
| v5 | v2 + mask floor 0.3 | 22.95 | 0.8324 |
| v6 | 두 검출기 마스크를 함께 입력 (5채널) | 23.17 | **0.8356** |
| V2-cap | 검출기 없이 capacity만 증가 | **23.22** | 0.8294 |

수치는 최종 보고서 Table 1의 SIDL Water 서버 평가 결과입니다. 모든 실험은 seed 42 단일 실행입니다.

v6에서 베이스라인보다 평균 PSNR이 0.60 dB 높아졌지만, 검출기 없이 모델 크기만 늘린 V2-cap의 PSNR이 더 높았습니다. 반대로 SSIM은 v6가 가장 높았습니다. 또 v6는 Medium에서 좋은 결과를 얻었지만 Hard에서는 v5의 성능을 따라가지 못했습니다. 마스크가 무조건 도움이 된다고 결론 내리기보다는, 어떤 부분에 도움이 되는지를 비교하는 데 의미가 있었습니다. 다른 시드와 오염 유형에 대해서는 추가 검증이 필요합니다.

보관 중인 코드는 NAFNet 기반 학습과 추론, 제출 파일 생성에 사용되는 Colab 노트북 두 버전 및 초기 설정 파일입니다. 보고서에 설명한 U-Net 검출기와 v1~v6의 전체 구현, 학습 가중치, 데이터셋은 현재 보관된 자료에 포함되어 있지 않습니다. 따라서 최종 실험을 그대로 재현할 수 있는 저장소는 아닙니다.
