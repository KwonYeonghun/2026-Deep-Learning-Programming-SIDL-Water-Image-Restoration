## 🚦 멈추고 점검해야 할 신호

다음 중 하나라도 발생하면 **바로 멈추고 디버깅**:

- 학습 시작 후 1000 iter 동안 loss가 안 내려감
- Val PSNR이 학습 진행 중인데 점점 떨어짐 (overfitting / divergence)
- OOM 자주 발생 → batch size 또는 patch size 줄이기
- 학습 epoch마다 시간이 점점 늘어남 → memory leak 의심
- Colab disconnect 후 resume 안 됨 → 체크포인트 경로 확인
