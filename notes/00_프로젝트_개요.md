# 00. 프로젝트 개요 — SIDL Image Restoration

## 무엇을 하는가

**SIDL (Smartphone Images with Dirty Lenses)** 벤치마크에서 상위권 진입.
- Task: 스마트폰 카메라 렌즈에 묻은 오염물(물방울/지문/먼지/긁힘) 제거
- 일종의 image restoration 문제 (denoising/deblurring 보다는 "lens contamination removal"에 더 가까움)

## 데이터셋 핵심 사실

| 항목 | 값 |
|---|---|
| 총 scene 수 | 300 |
| 총 paired image | 1,588 |
| 원본 해상도 | 4032 × 3024 (DNG RAW 12-bit) |
| Train / Val / Test | 240 / 20 / 40 scenes |
| 오염 유형 | 물방울 · 지문 · 먼지 · 스크래치 · 혼합 |
| 난이도 | Easy / Medium / Hard (PSNR 기반 분류) |
| 촬영 조건 | 실내·실외, 주간·야간, 3단계 조명 |

## 평가 지표

- **PSNR** (Peak Signal-to-Noise Ratio)
- **SSIM** (Structural Similarity Index)
- 위 두 지표를 Easy / Medium / Hard 각각 평균한 값들

## 베이스라인 6개 모델

| 모델 | 학회 | 특징 | 우리가 사용? |
|---|---|---|---|
| **NAFNet** | CVPR 2022 | 간단·빠름·강력 | ✅ 메인 베이스라인 |
| **Restormer** | CVPR 2022 | Transformer, 고품질 | ✅ 두번째 모델 |
| **MambaIR** | ECCV 2024 | Mamba/SSM | ✅ 세번째 (ensemble 용) |
| FFTformer | CVPR 2023 | Frequency-aware | ⚪ 시간 되면 |
| AirNet | CVPR 2022 | All-in-one | ❌ |
| DiffUIR | - | Diffusion 기반 | ❌ 학습 비용 너무 큼 |

## 목표

1. **1차 목표**: 베이스라인 모델들을 SIDL에 학습시켜 동작 검증
2. **2차 목표**: TTA + Ensemble + 강력한 augmentation으로 점수 상승
3. **최종 목표**: 리더보드 **상위권 (TOP 5~10)** 진입
4. (욕심) **TOP 1~3** — RAW domain training 또는 합성 데이터 증강으로 차별화
