# 학습 코드

프로젝트 자료에 남아 있는 NAFNet 기반 Colab 노트북과 초기 설정 파일을 보관하는 폴더입니다.

- `SIDL_NAFnet_share.ipynb`: 학습, 추론, 효율 측정 및 제출 파일 생성
- `SIDL_NAFnet_share_copy.ipynb`: 수정 사본
- `nafnet_config_sidl.yml`: 초기 학습 설정
- `colab_train_nafnet.ipynb_template.md`: 초기 Colab 학습 가이드

실행 전 Google Drive의 데이터 경로와 체크포인트 경로를 확인해야 합니다. 초기 설정은 최종 보고서의 실험 설정과 다릅니다. 최종 dual-mask 모델 전체 구현은 현재 보관된 자료에 없습니다.
