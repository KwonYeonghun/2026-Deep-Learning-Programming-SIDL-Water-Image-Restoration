| 목표 | 산출물 |
|---|---|
| Colab/데스크탑 환경 준비 | 동작하는 Python 환경 |
| 데이터셋 다운로드 (patch 버전) | Drive에 Train/Val/Test 정리 |
| NAFNet repo 세팅 + SIDL 데이터로더 | 첫 학습 시작 |

**Week 2 마일스톤**: 3개 모델 (NAFNet / Restormer / MambaIR) 각각 학습된 상태. 가장 강한 모델 식별.

---

## Week 3 (5/12 화 ~ 5/18 월) — Loss 튜닝 + Multi-scale + 장기 학습

| 목표 | 산출물 |
|---|---|
| Loss 조합 실험 (L1 + SSIM + FFT) | 가장 좋은 loss 비율 |
| Multi-scale training (patch 192 → 256 → 384) | high-res 디테일 향상 |
| Best config로 long training (300K~500K iter) | "최종" 모델 후보들 |
| SIDL 특화 augmentation 시도 (가짜 물방울 합성 등) | 차별화 포인트 |

**Week 3 마일스톤**: Long training 후 베스트 단일 모델 PSNR 28~29 dB.

---

## Week 4 (5/19 화 ~ 5/25 월) — Ensemble + TTA + 제출

| 목표 | 산출물 |
|---|---|
| TTA x8 self-ensemble 구현 | TTA inference 코드 |
| Model ensemble (3모델 평균) | 최종 prediction |

| 결과 분석 → 추가 개선 | 최종 제출 |

**Week 4 마일스톤**: 리더보드 등록 완료, 상위권 진입.
